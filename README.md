# 子俊的厨房账本

菜单、食谱、采购、记账放在一起的自用网站。纯静态网页，放在 GitHub Pages 上；数据存在 Supabase。

- `index.html`、`app.css`、`*.js`：网站本身，入口是 `app.js`
- `config.js`：Supabase 地址和 publishable key（留空时是本地模式，数据只存在浏览器里）
- `seed-recipes.json`：食谱种子。某道菜的 `v` 调大，网站下次打开会用这里的版本覆盖云端那道
- `seed-docs.json`：第一次打开时的记账、菜单、采购初始数据
- `schema.sql`：Supabase 建表和权限

改完推到 main 分支，GitHub Pages 一两分钟后自动更新。

## 粘贴小票

记一笔 → 粘贴小票。Claude 识别小票后给一段导入码，粘进去预览、确认后一次记好，可以撤销。一次可粘多张。

```
{"d":"2026-09-28","s":"Tesco","p":"card","l":[["food","",12.25,"Meal Deal 鸡胸肉"],["snack","",1.20,"巧克力"]]}
```

- `d` 日期，`s` 店名，`p` 付款（card / cash）
- `l` 每行 = [分类, "", 金额, 备注]，同一类合并成一行；分类写 id 或中文名都行
- 分类：food 吃饭 / snack 零食 / social 人情（请客、礼物、聚餐、跟朋友出去玩）/ trans 交通 / phone 话费 / other 其他（补剂、衣服护肤）；另外 stock 囤货（米、面粉、油、燕麦、大瓶调料、蛋白粉这类一买吃很久的，按种类判，从手上的钱扣，不占每月预算）
- 规则：超市正经食材、水、日用品、袋子钱、Meal Deal、外卖正餐算吃饭；糖、巧克力、薯片、奶昔、可乐汽水、奶茶咖啡算零食；蛋白棒这种正经营养的算吃饭；补剂、聚餐、衣服护肤、出去玩算其他；折扣按实付摊到对应东西
- once 一次性：锅、厨具这种一买用很久的，从手上的钱扣，不占每月预算
- 旧的分类 id（grocery / eat / supp / fun 带小类）也还认，会自动换成这五类
- 同一家店、同一天、同样总额的小票再粘会提醒可能重复

## Claude 直接记（inbox.json）

Claude 把识别好的账写进 `inbox.json` 推上来，网站打开（或切回页面）时自动记进账本，每批按 `id` 只记一次，记完弹提示可以撤销。

- `receipts`：和上面粘贴小票同样的格式
- `pay`：待付大额的名字（包含即可），标成已付；`payDate` 是付款日期
- `redo`：要改的旧小票 ["店|日期|总额", ...]（小写，总额去掉末尾 0，如 `first bus|2026-10-05|0.1`），先删掉记过的那几笔，再按这一批的 `receipts` 重记
- 新的一批就在 `batches` 里加一项、换一个新 `id`，旧的批次留着也不会重复记

## 家里的库存

inbox.json 的一批里可以带：
- `inv`：买回来的东西 [[采购名, 克数], ...]，`invFrom` 是从哪天的饭开始算消耗。网站按菜单往下扣，采购清单先扣掉家里还剩的
- `have`：囤货和调料的名字，标成「家里还有」
- `invSet: true`：按冰箱照片重新盘点，旧库存清掉换成这一份
- `regen`：日期。库存记好后从这天起把没锁的格子重排，用到家里现有东西的菜优先

## 排菜规则补充（2026-10-05）

- 早餐按 `data.js` 的 `BF`：工作日英式早餐（焗豆版排相邻两天），牛油果沙拉排相邻两天，周末从三明治、北非蛋里挑；早餐热量差 150 以上配恰巴塔（`bread` 克数），不配米饭
- 随机生成时，用到家里库存越多的菜越先排，放不久的肉菜奶算两分
- 食谱的 `prep: {when, t, mins}`：要提前一晚（或当天早上）腌、泡的。「今天」页的「今晚要做」会提醒，工作日午饭按前一晚做算

## 囤货池

米、燕麦、油、调料、蛋白粉、蜂蜜、咖啡这类一买用很久的记成 stock。每月预算里固定存一笔进囤货池（`S.pool.a`，默认 £30，从 2026-10 起），买囤货从池子扣，没用完滚到下个月，买多了先垫着后面补。2026-09 回来补的算开荒，不进池子。

## 大额分摊

一次性付的大额（`__one`）带 `spread: {start, months, plan}`，按月平摊进每个月的账。plan=true 是固定开销（健身房 9 个月、公交卡 3 个月、厨具 9 个月），这份同时加进当月预算；plan=false 是计划外的（生日请客分 3 个月），这份从当月预算里扣。`S.recur` 是会续费的（公交卡 £140 / 3 个月），算"钱能撑到哪天"时没预付到的月份会留出这份。

## 冰岛三人行（iceland/）

`iceland/index.html` 是 2026 年 12 月冰岛旅行的行程和签证攻略，单独一个页面，和厨房账本的数据无关。打开地址是网站后面加 `/iceland/`。
